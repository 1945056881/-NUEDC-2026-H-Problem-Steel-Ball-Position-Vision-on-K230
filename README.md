# K230 滚球视觉 —— 平衡摆杆小车钢球位置检测

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
![Platform](https://img.shields.io/badge/Platform-K230%20CanMV-blue)

基于 **CanMV K230** 的实时钢球位置检测程序，为 **2026 年全国大学生电子设计竞赛 H 题「车载平衡滚球运动控制系统」** 制作。

摄像头俯视 25 cm 绿色 PPR 摆杆。本程序在固定 ROI 内检测 1 cm 钢球，将像素坐标换算为**距摆杆左端的毫米位置**，并通过 UART 以 **最高 90 帧/秒** 的速率向主控发送带 CRC 保护的 10 字节二进制帧。

## 功能特性

- **90 FPS 检测**（640×480 RGB565），只处理摆杆附近的裁剪 ROI（约 601×65 像素），速度快且抗干扰。
- **LAB 阈值找绿色摆杆**：在 LAB 色彩空间分割绿色 PPR 管，形状过滤（长宽比 3~30），并用旋转矩形跟踪器（指数平滑 + 角点对应）稳定输出。
- **圆度评分找钢球**：按「宽高比 × 填充率相似度」评分黑色钢球；利用时间连续性加成，可以稳定跟踪快速运动产生的拖影，而不是丢球。
- **毫米输出**：球心投影到摆杆轴上，映射为 `0~250 mm`（左端为 0），可直接喂给主控 PID。
- **CRC-8 保护的 UART 帧**（`AA 55 ... CRC8`），支持无效位置上报与丢帧保持（启动后丢球时保持上次有效位置并用状态位标记）。
- **三面板 IDE 预览**（原图 / 二值 / 标定叠加）+ 轻量 FPS 与帧日志，便于现场调试。（可自行关闭，提升帧率）

```

K230 IO6（UART2 RX）◄────  主控 TX（可选，本程序未使用）
K230 GND            ────  共地
```

串口参数：**115200、8 数据位、无校验、1 停止位（8N1）**。

## 快速开始

1. 将 `k230_ball_vision.py` 用 CanMV IDE 打开运行。
2. 首次运行**保持预览开启**（程序固定开启），确认：
   - 画面方向正确（`CAMERA_HMIRROR` / `CAMERA_VFLIP`）；
   - ROI `(24, 146) – (625, 211)` 刚好包住摆杆（按你的安装位置调整 `ROI_TOP_LEFT` / `ROI_BOTTOM_RIGHT`）；
   - 绿色摆杆被正确检测（`LAB_THRESHOLD`），钢球被框出。
3. 调节 `LAB_THRESHOLD`（LAB 色彩空间），使 BINARY 面板中**摆杆为白色（前景）、背景和钢球为黑色**。
4. 标定（见[标定](#标定)）。
5. 将 IO5 接到主控 RX，检查串口日志帧，例如：

```
UART2 left_mm=125.0 valid=1 hold=0 tx=AA55...
```

6. 预览仅在调试时需要；正式运行时可保持开启（预览走 `Display.VIRT` IDE 通道，不影响 UART 发送）。

## UART 协议

固定 **10 字节** 二进制帧，小端序，每帧发送一次：

| 偏移 | 大小 | 内容 |
| ---: | --- | --- |
| 0 | 1 | `0xAA` 帧头 |
| 1 | 1 | `0x55` 帧头 |
| 2 | 1 | 帧序号，0~255 循环 |
| 3–4 | 2 | 球位置 `int16`，**单位 0.1 mm，距左端距离**（`0..2500` 即 `0..250 mm`） |
| 5–6 | 2 | 球速度 `int16`（当前恒为 0） |
| 7 | 1 | 置信度（255 有效 / 0 无效） |
| 8 | 1 | 状态位 |
| 9 | 1 | 对 0~8 字节的 CRC-8/ATM（多项式 0x07，初值 0x00） |

状态位：

| 位 | 含义 |
| --- | --- |
| 0 | 本帧位置有效 |
| 1 | 已标定（恒置 1） |
| 2 | 丢帧保持：检测丢失后发送的上次有效位置（启动 `UART_LOSS_HOLD_DELAY_MS` 之后生效） |

无效位置发送 `-32768`（`UART_INVALID_POSITION_X10`）。

电脑端解析工具见 [`docs/frame_parser.py`](docs/frame_parser.py)。

## 标定

像素→毫米映射采用**两点线性拟合**，且直接基于实时检测到的摆杆几何，无需手工填像素锚点：

1. 摆杆两个短边中点连线定义为**摆杆轴**；
2. 球心投影到该轴上；
3. 投影比例 × `BAR_LENGTH_MM = 250` 得到毫米位置。

因为映射是相对实时检测到的摆杆计算的，所以能自动容忍小幅安装偏移和画面中的摆杆旋转。唯一前提是摄像头在 ROI 内能看到**完整 25 cm 摆杆**。

验收步骤：

- 把钢球依次放在相对中心 −10、−5、0、+5、+10 cm 处；
- 读串口日志 `left_mm`，期望 75、100、125、150、175 mm（建议误差 ≤ ±2 mm）；
- 静止时中心抖动峰峰值 ≤ 3 mm；
- 全行程缓慢滚动时不应频繁出现 `BALL INVALID`；
- 关闭预览后检测帧率 ≥ 30 Hz（IDE 预览本身会把显示帧率限制在 60）。

## 关键参数

所有可调参数集中在 `k230_ball_vision.py` 顶部 "User settings" 区域。

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| `ROI_TOP_LEFT` / `ROI_BOTTOM_RIGHT` | (24,146) / (625,211) | 裁剪窗口，必须刚好包住摆杆 |
| `LAB_THRESHOLD` | (15,90,-66,-25,-28,39) | 选中绿色摆杆的 LAB 范围 |
| `BAR_MIN_LONG_SIDE_PX` 等 | 200 / 200 / 3.0 / 30.0 / 0.25 | 摆杆形状过滤（长边、短边、长宽比、填充率） |
| `RECT_SMOOTH_ALPHA` | 0.25 | 摆杆角点平滑；越小越平滑但延迟越大 |
| `RECT_MAX_CORNER_JUMP_PX` | 50.0 | 超过此值的角点跳变被拒绝 |
| `BALL_BLACK_THRESHOLD` | (0,20,-10,10,-10,10) | 选中黑色钢球的 LAB 范围 |
| `BALL_MIN/MAX_DIAMETER_PX` | 8 / 80 | 钢球尺寸过滤 |
| `BALL_MIN/MAX_ASPECT_RATIO` | 0.50 / 6.00 | 允许运动拖影形变 |
| `BALL_MIN_CIRCLE_SCORE` | 0.45 | 初次捕获的圆度阈值 |
| `BALL_MOTION_MIN_CIRCLE_SCORE` | 0.12 | 上一帧位置附近的跟踪圆度阈值 |
| `BALL_TRACK_SEARCH_DISTANCE_PX` | 160.0 | 连续性搜索半径 |
| `BALL_EDGE_MARGIN_PX` | 3 | 距摆杆边缘小于此值的候选被拒绝 |
| `BALL_MAX_AXIS_DISTANCE_RATIO` | 0.25 | 球心必须保持在摆杆宽度中央 50% 内 |
| `BAR_LENGTH_MM` | 250.0 | 摆杆物理长度，用于毫米换算 |
| `UART_LOSS_HOLD_DELAY_MS` | 5000 | 启动该时间后，丢球时保持上次有效位置 |
| `DIAGNOSTIC_LOGS` | False | 开启逐候选拒绝原因的完整诊断日志 |

## 工作原理

```text
snapshot（640x480 RGB565，90fps）
  └─ 裁剪 ROI ──► find_blobs(LAB_THRESHOLD)      绿色摆杆
  │                 └─ 形状过滤 ── min_corners() ── RectangleTracker（平滑/保持）
  │                                                    └─ 摆杆轴 = 两个短边中点连线
  └─ 二值图 ──► find_blobs(BALL_BLACK_THRESHOLD)     摆杆包围盒内的黑色钢球
                    └─ 几何 + 圆度评分 + 连续性 ── PointTracker
                                                      └─ 投影到摆杆轴
                                                         └─ 比例 × 250mm
                                                            └─ 10 字节 UART 帧
```

检测流程要点：

- **先检测并稳定摆杆**，再在摆杆包围盒内搜索钢球，因此球检测对摆杆以外的背景变化不敏感。
- 球的 `circle_score = 宽高比 × 填充率相似度` 可剔除管口碎块和反光，无需运行较慢的霍夫圆检测。
- 跟踪阶段，距上一帧球位置 `BALL_TRACK_SEARCH_DISTANCE_PX` 内的候选使用更低的圆度阈值并加分，从而锁住快速（拖影）运动的球。

## 与主控的对接约定

本程序是为 MSPM0G3507 主控配套设计的，主控侧：

- 在 UART RX 中断中解析 `AA 55 ... CRC8` 帧，并要求 `(flags & 0x03) == 0x03`、`0 ≤ position_x10 ≤ 2500`、置信度非 0；
- 将 `-32768` 视为无效，绝不送入控制环；
- 约 100 ms 收不到有效帧时进入安全状态；
- 位置单位为**距摆杆左端 0.1 mm**，因此 250 mm 摆杆的中心为 `1250`。

速度字段刻意恒为 0：由主控按自身控制周期对位置差分求速度，避免双重滤波。
